# Norte Constructora

Landing responsive para un estudio de arquitectura y construcción residencial.

## Desarrollo

```bash
npm install
npm run dev
```

## Producción

```bash
npm run build
```

Render publica la carpeta `dist` generada por Vite.

## Fuente principal

- `index.html`: estructura y contenido de la landing.
- `src/site.css`: sistema visual y adaptaciones responsive.
- `src/site.js`: navegación móvil, microinteracciones, video y formulario.
- `media/`: fotografías y recorrido 3D usados por el sitio.

Los componentes React heredados en `src/components/` no forman parte de la landing actual. Las próximas ediciones deben hacerse en los archivos indicados arriba.
